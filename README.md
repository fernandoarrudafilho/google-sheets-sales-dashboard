# Google Sheets Sales Dashboard

## Overview

This project was developed in Google Sheets to analyze sales performance and business metrics through dashboards, lookup functions, Pareto analysis, and visual reporting.

The objective was to transform raw sales data into actionable business insights using spreadsheet tools widely used in real companies.

---

## Tools & Skills Used

- Google Sheets
- Dashboards
- Charts & Visual Reporting
- VLOOKUP (PROCV)
- Pareto Analysis (80/20)
- KPI Monitoring
- Business Analysis
- Data Organization

---

## Project Highlights

- Interactive sales dashboards
- Revenue and profit monitoring
- Pareto analysis for top contributors
- Geographic sales insights
- Product category analysis
- Weekly sales behavior analysis

---

## Key Business Value

This project demonstrates the ability to solve business problems using spreadsheet tools without relying on programming languages, focusing on practical reporting and decision-making support.
